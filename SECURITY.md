# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through GitHub's **private vulnerability reporting** on this repository. Do not file security issues in public GitHub issues.

Do not include secrets, credentials, or personally identifiable information in your report.

## What not to report here

`SUPPORT_EMAIL` (if configured in your install) is for operator support, not vulnerability reports. Use the private reporting channel above.

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Response

We aim to acknowledge reports within a few business days and will work with reporters on a fix and disclosure timeline.
